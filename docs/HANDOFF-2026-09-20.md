## Gotchas learned this session

- `/usr/local/bin/git` and `gh` are Intel binaries with no Rosetta: use `/usr/bin/git` and
  `/opt/homebrew/bin/gh`.
- `npx cap sync ios` rewrites `CapApp-SPM/Package.swift`; restore it from git after every sync.
- Simulator taps via the iOS MCP need `attach` on the device first, and MLX cannot run there.
- Crash logs come off the phone with
  `xcrun devicectl device copy from --domain-type systemCrashLogs`; the phone must be unlocked.
- Playwright scripts must live inside the repo to resolve `playwright-core`; capture screenshots
  with a server on `RADIANT_PORT=5899` from the checkout, never the packaged app on 5834.
- A commit message that says only *what* fails ship-judge; say *why*.
- Scrubbed env for the agent's shell drops KEY/SECRET/TOKEN/PASSWORD/CREDENTIAL names, not AUTH
  (SSH_AUTH_SOCK).
